# H2 + 双 Sharpa SI · 独立开发分支

## 2026-09-27 迁移准备

目标：把现有 SI 调研、代码、依赖与交接说明整理进 `DexManip` 的 `si/h2-sharpa` 分支，在连接机器人的电脑上以独立目录继续开发。

- 保留 SI 实验路径、CLI 和 DDS 协议；五个原 USD 几何 helper 收进 `vendor/usd_geometry/`，先验常量抽成数据 JSON。删除仅供历史 demo CLI 使用的跨实验导入；不要求完整 DexRL、旧 H5、Isaac Sim、h5py 或另一套机器人模型。
- 现用 USD 及派生几何来自私有材料，不放公开 Git；六文件保持原字节，哈希清单公开，本地 bundle 约 29.77 MB。导入脚本拒绝缺文件、篡改、重复成员和路径穿越；manifest 旧绝对路径只作来源记录。
- 新 `.venv` 固定 NumPy 1.26.4、SciPy 1.15.3、trimesh 4.5.1、Rtree 1.3.0、matplotlib 3.10.3；所有入口改用当前 Python / `SI_PYTHON`，几何测试保留单线程 BLAS/OMP。
- CycloneDDS Python 0.10.2 在干净环境中要求原生库；安装入口按官方源码方法在本仓库 `.deps/` 编译原生 pin `9995905bce6c4cf9f740d6438bbf7fcfd1c83dfd`，再安装审计 SDK。Unitree 的 OpenCV 间接依赖也固定到 4.11.0.86，避免自动升级到要求 NumPy 2 的版本破坏离线环境。
- 新环境全套测试曾在 Rtree stream/ctypes callback 构造索引处 native abort；根因未确证。改为逐条插入同样完整的 padded AABB，规避观察到的 callback 路径；新增索引候选与穷举逐项一致测试。没有删网格、改变碰撞排除项或改算法判据。
- 发布材料不包含同事工作区快照、登录信息、私有模型、真实采集或生成计划。未在机器人电脑执行任何命令。

验证：迁移后的 SI 套件 **42 项通过、无跳过**（包含实际 USD），bundle 工具 **6 项通过**；单关节 ±2° / 0.25° USD 规划与原始网格预览成功。独立 Python 环境完成 DDS SDK 与四类消息 IDL 的导入检查，未建立 DDS participant 或 publisher。合成 demo 通过。另从 Git 暂存树导出全新目录：缺模型时完整 USD 入口如期返回失败；导入迁移包后 42 + 6 项测试通过，完整 58/58 关节 USD 规划通过。`pip check` 无依赖冲突。这些结果均为软件验证，不是真机 SI。

## 已有离线结果与边界

原 SI 工作区的名义候选中，双手与双臂 58 个关节的 ±2° 区间通过 990 个离散姿态检查，固定头腰腿 17 个关节。默认名义姿态不是真机当前姿态；只有 `usd-plan --from-run` 会使用真实记录并额外检查进入路径。旧轨迹不随此分支提交，应在新环境重新生成。

当前代码没有主动运动执行器、bridge 端超时处理或命令所有权机制。上游 bridge 会重发最后目标；停掉本地脚本不等于停止机器人。没有修改训练配置，也没有把一阶响应参数冒充 PD、惯量或真实关节摩擦。
